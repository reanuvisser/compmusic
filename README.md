# Phonk Outlier Analysis: Brazil vs. Russia

Welcome to my computational music project! 

**The live website is running at:** [https://reanuvisser.github.io/compmusic/](https://reanuvisser.github.io/compmusic/)

## About This Project

This project asks a clear question. Can computer analysis capture the differences between Brazilian Phonk and Russian Drift Phonk? 

To answer this, I analyzed a set of tracks from two different Spotify playlists. I looked at several audio features to see exactly how the two styles compare. 

Here is what the project covers:
* **Harmony:** Looking at musical keys and pitch using chroma features.
* **Loudness and Rhythm:** Comparing the tempo (BPM) and overall energy levels.
* **Time and Texture:** Studying the beat drops and how the sound changes over time.
* **Machine Learning:** Training a Random Forest model to see if a computer can tell the two genres apart.

## Tools Used

This project was built using R and Quarto. It relies on data from the Spotify API. It also uses R packages like `tuneR` and `seewave` to study the actual sound files.
